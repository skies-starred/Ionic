# **Ionic**

A  very cool "QoL" mod that's focused on general and slayer "QoL" features!

## Links

- Discord: https://discord.gg/3KnxwHRn2x
- Issues: please make reports in the discord instead of GitHub issues

## Features

### General
- Auto clicker
- Auto conversation
- Auto dojo
- Auto experiments
- Auto fish
  - Auto hyperion
  - Auto FB
- Auto harp
- Auto loadout
- Auto refill
- Auto sell
- Auto sprint
- Auto wardrobe
- Crystal hollow triggerbot
- Escrow fix
- Left click etherwarp
- Loadout keybinds
- Snap tap
- Trevor ESP and auto call
- Wardrobe keybinds

### Render
- Camera tweaks
- Ghost ESP
- Pest ESP
- Rat ESP
- Trajectories

### Slayer
- Anti boss grief
- Auto deployable
- Auto dagger
- Auto soulcry
- Auto twilight
- Boss ESP
- Miniboss ESP
